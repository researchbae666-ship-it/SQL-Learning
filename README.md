# SQL Learning

This repository archives 64 chapters of the user-provided *SQL* educational ebook and, in later steps, individual SQL tutoring lessons.

## Source and attribution

*SQL* (unofficial Stack Overflow Documentation ebook, Steve Nouri compilation; material originally contributed to Stack Overflow Documentation). The source PDF states its content is released under Creative Commons Attribution-ShareAlike (CC BY-SA). Each chapter archive retains source attribution and original reading links. See the textbook's full credits for chapter-specific contributors.

**Status:** Textbook chapter archive being initialized. Lesson/chat archives are a separate later step.

**Note:** The source material covers multiple SQL dialects. Our practical lessons use Microsoft SQL Server 2012 syntax, and are not identical to the original book's cross-dialect examples.
