# C13-L07: NCHAR and NVARCHAR

## Textbook excerpt

NCHAR and NVARCHAR

UNICODE string data types of either fixed length or variable length.

Syntax:

 NCHAR [ ( n_chars ) ]
 NVARCHAR [ ( n_chars | MAX ) ]


Use MAX for very long strings that may exceed 8000 characters.
