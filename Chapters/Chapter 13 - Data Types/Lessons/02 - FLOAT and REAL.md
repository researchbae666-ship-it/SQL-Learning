# C13-L02: FLOAT and REAL

## Textbook excerpt

FLOAT and REAL

Approximate-number data types for use with floating point numeric data.

 SELECT CAST( PI() AS FLOAT) --returns 3.14159265358979
 SELECT CAST( PI() AS REAL) --returns 3.141593
