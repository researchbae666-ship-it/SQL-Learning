# C32-L04: SAP ASE: Drop index

## Textbook excerpt

SAP ASE: Drop index

This command will drop index in the table. It works on SAP ASE server.

Syntax:

 DROP INDEX [table name].[index name]


Example:

 DROP INDEX Cars.index_1
