# C52-L12: REGEXP

## Textbook excerpt

REGEXP

MySQL3.19

Checks if a string matches a regular expression (defined by another string).

 SELECT 'bedded' REGEXP '[a-f]' -- returns True

 SELECT 'beam' REGEXP '[a-f]' -- returns False
