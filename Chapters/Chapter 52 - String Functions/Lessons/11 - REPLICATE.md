# C52-L11: REPLICATE

## Textbook excerpt

REPLICATE

The REPLICATE function concatenates a string with itself a specified number of times.

Syntax is: REPLICATE ( string-expression , integer )

 SELECT REPLICATE ('Hello',4) --returns 'HelloHelloHelloHello'
