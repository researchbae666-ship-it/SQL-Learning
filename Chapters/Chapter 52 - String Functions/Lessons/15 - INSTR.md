# C52-L15: INSTR

## Textbook excerpt

INSTR

Return the index of the first occurrence of a substring (zero if not found)

Syntax: INSTR ( string, substring )

 SELECT INSTR('FooBarBar', 'Bar') -- return 4
 SELECT INSTR('FooBarBar', 'Xar') -- return 0
