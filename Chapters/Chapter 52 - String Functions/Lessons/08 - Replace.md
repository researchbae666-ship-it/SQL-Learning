# C52-L08: Replace

## Textbook excerpt

Replace

Syntax:

REPLACE( String to search , String to search for and replace , String to place into the original string
)

Example:

 SELECT REPLACE( 'Peter Steve Tom', 'Steve', 'Billy' ) --Return Values: Peter Billy Tom
