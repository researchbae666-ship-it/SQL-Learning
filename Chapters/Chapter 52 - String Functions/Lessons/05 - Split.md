# C52-L05: Split

## Textbook excerpt

Split

Splits a string expression using a character separator. Note that STRING_SPLIT() is a table-valued
function.

 SELECT value FROM STRING_SPLIT('Lorem ipsum dolor sit amet.', ' ');


Result:

 value
 -----
 Lorem
 ipsum
 dolor
 sit
 amet.
