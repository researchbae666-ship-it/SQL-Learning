# C31-L01: Simple IN clause

## Textbook excerpt

Chapter 31: IN clause
Examples
Simple IN clause

To get records having any of the given ids

 select *
 from products
 where id in (1,8,3)


The query above is equal to

 select *
 from products
 where id = 1
    or id = 8
    or id = 3
