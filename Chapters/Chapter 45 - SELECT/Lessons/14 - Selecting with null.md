# C45-L14: Selecting with null

## Textbook excerpt

Selecting with null

 SELECT Name FROM Customers WHERE PhoneNumber IS NULL





Selection with nulls take a different syntax. Don't use =, use IS NULL or IS NOT NULL instead.
