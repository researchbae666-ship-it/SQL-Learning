## What the teaching conversation covered

The Chapter 1 review taught the difference between *SQL, the standardized query language*, and Microsoft SQL Server, a database product implementing a SQL dialect. Other SQL implementations (MySQL, PostgreSQL) were used as comparisons. The SQL standard timeline from SQL-86 to SQL:2016 was reviewed; memorizing each date was not required.

**Core distinction taught:** "SQL:2011 is a language standard. Microsoft SQL Server 2012 is a database product version. They aren't the same numbering system."

## Verbatim assessment submissions for this lesson

**Q1. SQL versus SQL Server — 4/4:**

**Q2. Standard versus product release — 4/4:**

> SQL:2011 is an international ANSI/ISO database query language standard, whereas SQL Server 2012 is a specific relational database management system (RDBMS) product built and sold by Microsoft.
