## Topics taught and tested

- SQL is used with relational database systems.
- DDL = Data Definition Language; example: CREATE.
- DML = Data Manipulation Language; example: INSERT.
- DCL = Data Control Language; example: GRANT.
- CRUD = Create/Read/Update/Delete; mapped respectively to INSERT/SELECT/UPDATE/DELETE.
- MERGE can perform INSERT, UPDATE and DELETE write actions, with detailed syntax deferred to Chapter 38.

## Corrective note (outside Chapter 1 textbook discussion)

In SQL Server 2012, many DDL operations can run within explicit transactions; their effects may be rolled back. The initial statement that DDL changes are typically permanent and automatically committed should not be treated as a universal rule.
